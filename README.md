# Schreibwerkstatt Wiesbaden 8 – Donation Webpage (Gift Project)

This repository contains a small website created as a **donation / gift project by me** for **Schreibwerkstatt Wiesbaden 8**.

It is a simple webpage intended to be embedded and shown as a **fragment inside the host’s WordPress website**.

## Purpose

- Provide a clean donation/info section for Schreibwerkstatt Wiesbaden 8
- Lightweight and easy to integrate into WordPress
- Simple to maintain and update

## Integration

Upload the files to the hosting server and include/embed the fragment in the WordPress site (e.g. via an HTML block, shortcode, or theme/template integration).
